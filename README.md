# LiteCode
Este projeto foi criado com o objetivo de ajudar pessoas que não conseguem utilizar o VS Code por conta do alto consumo de recursos do computador.

Pensando nisso, desenvolvi meu próprio editor de código, chamado **LiteCode**, focado em leveza, desempenho e acessibilidade, especialmente para quem utiliza PCs mais fracos.

A ideia é oferecer uma experiência de programação simples, rápida e eficiente, consumindo o mínimo de recursos possível e permitindo que mais pessoas possam programar sem se preocupar tanto com as limitações do hardware.

**LiteCode — programação acessível para todos, até mesmo em PCs mais modestos.**
